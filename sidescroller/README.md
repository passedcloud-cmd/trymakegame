# 🗡️ 작은 기사와 벌레 숲 (가제)

숲을 차지한 벌레들을 물리치는 **2D 횡스크롤 액션 RPG**예요.
주인공은 하얀 투구를 쓴 **작은 기사**예요. 할로우 나이트처럼 방향키로 움직이고, 벌레의 공격을 피하면서 검으로 물리쳐요.

- 엔진: Godot 4.4 이상 (Standard 버전)
- 화면: 320×180 픽셀 아트 (창 크기 1280×720)
- 목표: itch.io 웹 배포

## 실행 방법
1. Godot을 켜고 **가져오기(Import)** → 이 `sidescroller` 폴더 안의 `project.godot`을 선택해요.
   - ⚠️ 저장소 맨 위의 `project.godot`은 다른 게임(별똥별 줍는 여우)이에요. 꼭 **`sidescroller` 안의 것**을 골라요.
2. 오른쪽 위의 ▶ 버튼(또는 F5)을 누르면 타이틀 화면부터 시작해요.
   - 한 맵만 바로 시험해 보고 싶으면 그 장면(예: `scenes/stage_1.tscn`)을 열고 **F6**(현재 장면 실행)을 눌러요.

## 조작
| 키 | 동작 |
|---|---|
| ← → | 걷기 |
| Z / 스페이스 | 점프 (짧게 누르면 낮게, 길게 누르면 높게) |
| X | 검 휘두르기 |
| ↑ + X | 위로 베기 |
| 공중에서 ↓ + X | 아래로 베기. 벌레나 가시를 맞히면 **통통 튀어 올라요** |
| C / Shift | 대시 (공중에서 1번 가능). **대시하는 동안은 무적!** |
| ↑ | NPC·표지판과 이야기하기 |
| Z / X / 스페이스 / 엔터 | 대사 넘기기, 메뉴 고르기 |
| ESC | 잠깐 쉬기 (계속하기 / 마을로 돌아가기 / 타이틀 화면으로) |
| M | 소리 끄기/켜기 |

게임패드도 돼요: 십자키·왼쪽 스틱 이동, A 점프, X 공격, B·RB 대시, Start 잠깐 쉬기.
키를 바꾸려면 **프로젝트 → 프로젝트 설정 → 입력 맵** 탭에서 바꿔요.

## 🎮 게임 구성
```
타이틀 ─→ 🏡 풀잎 마을 ─(숲으로 가는 문)─→ STAGE 1 이끼 숲길
              ↑                         ─→ STAGE 2 푸른 동굴     (1을 깨면 열려요)
              └──── 클리어하면 돌아와요 ─── STAGE 3 투구벌레 둥지 (2를 깨면 열려요, 보스!)
                                                  └─ 처음 깨면 엔딩 🎉
```
- **스테이지**: 가로로 긴 맵이에요. 화면 오른쪽 위의 **남은 벌레** 숫자가 0이 되면 **스테이지 클리어!**
- **쓰러지면** 그 스테이지를 처음부터 다시 해요. (모은 빛조각은 그대로 남아요)
- **구덩이나 가시**에 빠지면 가면(체력)이 하나 깨지고, 마지막으로 밟은 안전한 땅에서 다시 서요.
- **빛조각**(돈): 벌레가 떨어뜨려요. 가까이 가면 저절로 빨려 와요. 스테이지를 처음 깨면 보너스 20개, 다시 깨면 5개.
- 가끔 벌레가 **회복 하트**를 떨어뜨려요. (가면 1칸 회복)
- 마을에 들어오면 체력이 가득 차요.

### 🐛 벌레들
벌레는 공격하기 전에 **꼭 티를 내요.** 그걸 보고 피하는 게 이 게임의 재미예요!

| 벌레 | 체력 | 공격 | 공격 전 신호 | 장면 파일 |
|---|---|---|---|---|
| 이끼벌레 | 20 | 왔다 갔다 걷기 (닿으면 아파요) | - | `scenes/enemies/crawler.tscn` |
| 뿔딱정벌레 | 40 | 빠르게 돌진 | 눈이 빨개지고 부르르 떨어요 | `scenes/enemies/charger.tscn` |
| 가시벌 | 20 | 날아다니며 침 쏘기 | 몸이 주황색으로 반짝여요 | `scenes/enemies/flyer.tscn` |
| 통통벼룩 | 30 | 기사 쪽으로 크게 뛰어오르기 | 몸을 납작 웅크려요 | `scenes/enemies/hopper.tscn` |
| 👑 투구벌레 대장 | 260 | 돌진 / 점프 쿵 / 침 뿌리기 | 몸이 빨개지고 "삐삐" 소리 | `scenes/enemies/boss.tscn` |

**투구벌레 대장과 싸우는 법**
| 대장의 공격 | 피하는 법 |
|---|---|
| 💨 돌진 | 대시로 통과하거나 점프로 넘어요. 벽에 부딪히면 **어지러워해요 → 마음껏 때릴 기회!** (어지러울 때는 닿아도 안 아파요) |
| 🪨 떨어지는 돌 | 벽에 부딪힌 뒤 천장에서 떨어져요. 바닥의 **빨간 표시**를 보고 피해요 |
| 💥 점프 쿵 | 떨어지는 곳에서 벗어나요. 양옆으로 퍼지는 **충격파는 점프**로 넘어요 |
| 🔮 침 뿌리기 | 부채꼴로 날아오는 침 사이로 피해요 |
| 😡 체력 절반 이하 | 화가 나서 더 빨라지고, 돌과 침이 늘어나요 |

### 🏡 마을 사람들
| NPC | 하는 일 | 스크립트 |
|---|---|---|
| 👴 촌장 할아버지 | 이야기와 다음에 갈 곳을 알려줘요 | `scripts/npcs/elder.gd` |
| 🔨 대장장이 브론 | 빛조각 30 / 70개 → **검 강화** (공격력 10 → 14 → 19) | `scripts/npcs/smith.gd` |
| 🌿 약초상 리나 | 빛조각 40 / 90개 → **최대 체력 +1** (최대 2번) | `scripts/npcs/herbalist.gd` |
| 🧒 꼬마 피피 | 말을 걸 때마다 다른 꿀팁 | `scripts/npcs/kid.gd` |
| 🌀 숲으로 가는 문 | 갈 스테이지 고르기 (깬 곳은 ★) | `scripts/npcs/gate.gd` |

- **대사 고치기:** 각 스크립트 안의 글을 고치면 돼요. 표지판 글은 맵 파일(`levels/*.txt`)의 `---` 아래에 있어요.
- **새 NPC 만들기:** `scenes/npcs/npc.tscn`을 마을 장면의 `NPCs` 아래로 끌어다 놓고, 인스펙터에서 **Npc Name**(이름)과 **Lines**(대사)를 적어요. 특별한 행동을 하게 하려면 `smith.gd`처럼 `extends NPC`로 시작하는 스크립트를 만들어요.
- 선택지는 `await Dialogue.ask(이름, 질문, ["예", "아니요"])`로 물어볼 수 있어요. 고른 번호(0부터)가 돌아와요.

## 🗺️ 맵 고치기 (글자로 그리기)
맵은 `levels/` 폴더에 **글자로 그린 텍스트 파일**로 들어 있어요. 글자 한 칸이 게임 속 16×16 픽셀 한 칸이에요.

```
..........................c.........
......................========......   ← = 발판 (아래에서 뚫고 올라가요)
..P..S.........c..............b.....   ← P 출발, S 표지판, c/b 벌레
########...########^^^##############   ← # 땅, ^ 가시, 빈칸(.)은 구덩이
```

| 글자 | 뜻 | 글자 | 뜻 |
|---|---|---|---|
| `#` | 땅 | `c` | 이끼벌레 |
| `=` | 발판 | `b` | 뿔딱정벌레 |
| `^` | 가시 | `f` | 가시벌 |
| `P` | 기사 출발 위치 | `h` | 통통벼룩 |
| `S` | 표지판 | `B` | 투구벌레 대장 |

마을에서는 `E` 촌장, `K` 대장장이, `R` 약초상, `k` 꼬마, `G` 문, `1` `2` `3` 집, `F` 대장간, `T` 나무, `L` 가로등을 써요.

**맵을 고친 뒤 장면 다시 만들기** (터미널에서 `sidescroller` 폴더 안에서):
```
godot --headless --script tools/build_levels.gd
```
- `godot` 자리에는 Godot 실행 파일의 경로를 적어요. (예: 윈도우 `"C:\Godot\Godot_v4.4.1-stable_win64.exe"`)
- 이 명령은 `scenes/village.tscn`, `scenes/stage_1~3.tscn`을 **새로 만들어요.** Godot 에디터에서 그 장면에 직접 고친 내용은 사라지니, 글자로 고칠지 에디터로 고칠지 한 가지만 쓰는 게 좋아요.
- 에디터로 고칠 때: 장면을 열고 `Ground`를 선택한 뒤 아래 **TileMap** 탭에서 타일을 칠해요. 벌레는 `scenes/enemies/` 안의 장면을 `Enemies` 아래로 끌어다 놓아요.
- **스테이지 추가하기:** `levels/stage_4.txt`를 만들고 → `tools/build_levels.gd`의 `LEVELS`에 한 줄 → `scripts/game_state.gd`의 `STAGES`에 한 줄 추가하면 돼요.

## ⚙️ 숫자 바꾸기 (난이도 조절)
Godot에서 장면을 열고 맨 위 노드를 선택하면 오른쪽 **인스펙터**에 설명이 달린 숫자들이 있어요.
- **기사:** `scenes/player.tscn` → 달리기 빠르기, 점프 힘, 대시 시간, 무적 시간 등
- **벌레:** `scenes/enemies/*.tscn` → 체력(Max Hp), 떨어뜨리는 빛조각(Shard Drop), 속도, 공격 준비 시간(Windup Time) 등
  - 공격 준비 시간(Windup Time)을 늘리면 피하기 쉬워져요.
- **체력·공격력:** `scripts/game_state.gd`의 `BASE_HP`(기본 가면 5개), `SWORD_DAMAGE`
- **가격:** `smith.gd`, `herbalist.gd`의 `COSTS`
- **클리어 보너스:** 스테이지 장면의 Clear Reward / Replay Reward

## 🔊 소리
효과음과 배경 음악도 `tools/make_sounds.py`로 만든 임시 소리예요. (파이썬만 있으면 실행돼요)
- `assets/music/`: `village`(마을·타이틀), `forest`(1스테이지), `cave`(2스테이지), `boss`(3스테이지), `ending`
- `assets/sounds/`: `jump`, `swipe`, `hit`, `hurt`, `dash`, `pogo`, `warn`(공격 준비), `shard`, `clear` 등 25개
- 다운받은 WAV 파일로 **같은 이름으로 덮어쓰면** 돼요. 새 음악은 Godot에서 파일 선택 → **가져오기 탭 → Loop Mode: Forward** → 다시 가져오기.
- 코드에서 소리 내기: `Sound.play("효과음 이름")`, `Sound.play_music("음악 이름")`

## 💾 저장
진행 상황(빛조각, 검 레벨, 체력, 깬 스테이지)은 **자동 저장**돼요: 마을에 들어올 때, 물건을 살 때, 스테이지를 깼을 때.
타이틀 화면에서 **이어하기**로 계속해요. 웹 버전에서는 브라우저 안에 저장돼요.

## 🚀 itch.io에 올리기
1. Godot 에디터에서 **에디터 → 내보내기 템플릿 관리 → 다운로드 및 설치**를 해요. (처음 한 번만)
2. **프로젝트 → 내보내기** → 이미 만들어 둔 **Web** 설정을 고르고 → **프로젝트 내보내기** → `build/web/index.html`로 저장해요.
   - Web 설정은 `export_presets.cfg`에 들어 있어요. itch.io에서 잘 돌아가도록 **Thread Support는 꺼 두었어요.**
3. `build/web` 폴더 **안의 파일들**(index.html 등)을 모두 골라서 ZIP으로 압축해요. (폴더째 압축하지 말고 파일들을 압축해요)
4. itch.io → **Upload new project**
   - Kind of project: **HTML**
   - ZIP 파일을 올리고 **"This file will be played in the browser"** 체크
   - Viewport dimensions: **1280 × 720** (또는 960 × 540)
   - **Fullscreen button** 체크를 추천해요.
5. 저장하고 페이지를 열어서 잘 되는지 확인해요!

## 폴더 구조
| 폴더 | 들어 있는 것 |
|---|---|
| `scenes/` | 화면과 캐릭터 (`.tscn`). 벌레는 `enemies/`, 마을 사람과 표지판은 `npcs/` |
| `scripts/` | 움직임을 정하는 코드 (`.gd`) |
| `levels/` | 글자로 그린 맵 (`.txt`) |
| `assets/` | 그림, 소리, 글꼴 |
| `tools/` | 그림·소리·맵을 만드는 스크립트 |

| 게임 어디서든 쓰는 것 (자동 로드) | 하는 일 |
|---|---|
| `GameState` (`scripts/game_state.gd`) | 빛조각, 검 레벨, 깬 스테이지, 저장하기 |
| `Sound` (`scripts/sound.gd`) | 효과음, 배경 음악 |
| `Dialogue` (`scenes/dialogue_box.tscn`) | 화면 아래 대화창, 선택지 |
| `Transition` (`scenes/transition.tscn`) | 장면을 바꿀 때 까맣게 됐다가 밝아지는 효과 |
| `PauseMenu` (`scenes/pause_menu.tscn`) | ESC 잠깐 쉬기 창 |
