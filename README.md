# 🦊 별똥별 줍는 여우 (가제)

하늘에서 떨어진 별 3개를 되찾아 어둠에 잠긴 동물 마을을 다시 밝히는 2D 픽셀 어드벤처 게임이에요.
주인공은 꼬마 여우 **코랄**이에요.

- 엔진: Godot 4.4 이상 (Standard 버전)
- 목표: itch.io 웹 배포

## 실행 방법
1. 이 저장소를 **Code → Download ZIP**으로 받아서 압축을 풀어요.
2. Godot을 켜고 **가져오기(Import)** → 압축 푼 폴더 안의 `project.godot` 선택
3. 오른쪽 위의 ▶ 버튼(또는 F5)을 누르면 게임이 실행돼요.

## 조작
| 키 | 동작 |
|---|---|
| 방향키 | 이동 |
| Z / 스페이스 / 엔터 | NPC와 대화, 대사 넘기기, 선택지 고르기 |
| ↑ / ↓ (대화 중) | 선택지 옮기기 |
| X | 꼬리 휘두르기 (공격) |
| C / Shift | 대시 (첫 번째 별을 주운 뒤부터) |
| V | 별빛 켜기/끄기 (두 번째 별을 주운 뒤부터) |

## 폴더 구조
| 폴더 | 들어 있는 것 |
|---|---|
| `scenes/` | 게임 화면과 캐릭터 (`.tscn` 파일) |
| `scripts/` | 움직임 같은 동작을 정하는 코드 (`.gd` 파일) |
| `assets/` | 그림 파일 (`.png`). 마을 그림은 `assets/village/` |
| `tools/` | 임시 그림과 바닥 타일을 만드는 스크립트 (마을, 동굴, 보스) |

## 🎨 그림 바꾸기
`assets/` 안의 그림은 임시로 만든 거예요. 다운받은 에셋으로 **같은 이름으로 덮어쓰면** 바로 바뀌어요.

| 파일 | 크기 | 설명 |
|---|---|---|
| `owl_chief.png` | 32×16 | 부엉이 촌장. 16×16 그림 2칸 (눈 뜸, 눈 감음) |
| `talk_icon.png` | 11×8 | NPC 머리 위 말풍선 |
| `raccoon_merchant.png` | 32×16 | 너구리 상인 (눈 뜸, 눈 감음) |
| `timid_rabbit.png` | 32×16 | 겁많은 토끼 (눈 뜸, 눈 감음) |
| `baby_rabbit.png` | 32×16 | 아기 토끼 (눈 뜸, 눈 감음) |
| `turtle_grandma.png` | 32×16 | 거북이 할머니 (눈 뜸, 눈 감음) |
| `acorn.png` | 8×8 | 도토리 |
| `shadow_slime.png` | 32×16 | 그림자 슬라임. 16×16 그림 2칸 (보통, 납작) |
| `heart_full.png` / `heart_empty.png` | 9×8 | 체력 하트 |
| `tail_swipe.png` | 16×24 | 꼬리 휘두르기 효과 (오른쪽 방향으로 그려요) |
| `coral.png` | 64×48 | 16×16 그림이 가로 4칸(걷기 동작) × 세로 3줄 |
| `rock.png` | 32×32 | 바위 |

`coral.png`의 줄 순서는 1줄 **아래 보기**, 2줄 **위 보기**, 3줄 **오른쪽 보기**예요. 왼쪽 보기는 3줄을 좌우로 뒤집어서 써요.

**다운받은 그림의 칸 수나 줄 순서가 다르다면?**
1. Godot에서 `scenes/player.tscn`을 열고 `Sprite2D`를 선택해요.
2. 오른쪽 인스펙터의 **Animation → Hframes(가로 칸 수) / Vframes(세로 줄 수)**를 그림에 맞게 바꿔요.
3. `Player`를 선택하고 인스펙터의 **Row Down / Row Up / Row Side**에 방향별 줄 번호를 넣어요. 줄 번호는 0부터 세요.

## ⭐ 별과 능력
| 별 | 있는 곳 | 얻는 능력 |
|---|---|---|
| 첫 번째 별 | 동쪽 숲 오솔길 끝 | **대시**: 부서진 다리의 틈을 건널 수 있어요 |
| 두 번째 별 | 강 건너 캄캄한 동굴 안쪽 | **별빛**: 넓게 밝히고, 슬라임을 쫓고, 그림자 장막을 걷어내요 |
| 세 번째 별 | 그림자 곰의 굴 (보스) | - (별 세 개를 모두 돌려보내면 엔딩!) |

- 별을 주워서 **부엉이 촌장**에게 가져가면 별이 하늘로 돌아가고 **마을이 조금 밝아져요.**
- 다리 틈은 `village_tilemap.tscn`의 **끊어진 틈 타일**이에요. 이 타일은 충돌 레이어 2에 있어서, 대시하는 동안만 지나갈 수 있어요.
- 대시 속도와 시간은 `player.tscn` → `Player`의 **대시** 칸에서 바꿀 수 있어요.

### 두 번째 별 가는 길
1. 첫 번째 별을 돌려보낸 뒤 **거북이 할머니**에게 말을 걸면 **반딧불이 병**을 줘요. 코랄 주위가 은은하게 밝아져요.
2. 강 건너 **캄캄한 동굴**에 말을 걸면 안으로 들어갈 수 있어요. (`scenes/cave.tscn`)
3. 동굴은 아주 어두워요. 파란 수정이 길잡이가 돼요.
4. 두 번째 별을 주우면 **별빛**을 배워요. 보라색 **그림자 장막**에 다가가면 사라져요.
   - 하나는 입구로 가는 지름길, 하나는 **빛나는 버섯**(최대 체력 +1)이 있는 숨겨진 방을 막고 있어요.
5. 동굴 아래쪽 출구로 나와서 부엉이 촌장에게 별을 가져가요.

### 마지막 장: 그림자 곰
1. 두 번째 별을 돌려보내면 부엉이 촌장이 그림자 곰의 굴을 알려줘요.
2. 강 건너 바위 지대 **남쪽 끝**의 그림자 장막을 별빛으로 걷어내고 내려가면 **그림자 곰의 굴**이에요. (`scenes/den.tscn`)
3. 그림자 곰과 싸우는 방법:

| 곰의 행동 | 대처법 |
|---|---|
| 🛡️ 그림자 갑옷 (꼬리가 "팅!" 하고 튕겨요) | 가까이서 **별빛**을 1초 비추면 갑옷이 벗겨지고 어질어질해져요. 그때 꼬리로 때려요! |
| 💨 돌진 | **대시**로 피해요. 곰이 벽에 부딪히면 어질어질해져요! |
| 🔮 그림자 구슬 | 구슬 사이로 피해요 |
| 💥 땅 내려치기 | 분홍 동그라미가 나오면 얼른 벗어나요. 곧 가시가 솟아요 |
| 😡 체력 절반 이하 | 더 빨라지고, 슬라임 2마리를 불러요 |

- 어질어질에서 깨어난 뒤 4초 동안은 갑옷이 단단해서 별빛이 안 통해요.
- 곰의 체력과 공격 속도는 `scenes/shadow_bear.tscn` → `ShadowBear`의 인스펙터에서 바꿀 수 있어요.
4. 곰을 이기면 그림자가 녹아내리고 **아기 곰**이 나와요. 세 번째 별을 받아서 부엉이 촌장에게 가져가면 **마을이 완전히 밝아지고 엔딩**이 나와요.
5. 아기 곰은 그 뒤로 마을 광장에서 지내요.

### 맵 이동
- 다른 맵으로 갈 때는 `Transition.go("장면 파일", "출발 지점 이름")`을 써요. 화면이 까맣게 됐다가 밝아져요.
- 출발 지점은 `spawn` 그룹에 들어 있는 **Marker2D**예요. (마을의 `FromCave`, 동굴의 `Entrance`)
- 걸어서 닿으면 이동하는 출구는 `scenes/exit_area.tscn`이에요.
- 코랄이 쓰러지면 **그 맵에 마지막으로 들어온 곳**에서 다시 깨어나요.

## 🏡 마을 사람들
| NPC | 하는 일 | 대사가 있는 곳 |
|---|---|---|
| 🦉 부엉이 촌장 | 이야기를 이끌고, 별을 하늘로 돌려보내 줘요 | `scripts/owl_chief.gd` (첫 대사는 `OwlChief`의 Lines) |
| 🦝 너구리 상인 | 도토리 2개 → 회복 열매 (체력 가득 회복) | `scripts/raccoon_merchant.gd` |
| 🐰 겁많은 토끼 | 잃어버린 동생 찾기 퀘스트. 보상은 최대 체력 +1 | `scripts/timid_rabbit.gd` |
| 🐇 아기 토끼 | 맵 오른쪽 아래에서 길을 잃었어요 | `scripts/baby_rabbit.gd` |
| 🐢 거북이 할머니 | 말을 걸 때마다 다른 옛날이야기. 동굴에 갈 때 반딧불이 병을 줘요 | `scripts/turtle_grandma.gd` |

도토리 개수, 별, 퀘스트 진행 상황은 `scripts/game_state.gd`에 모여 있어요. 코랄이 쓰러지면 집 앞에서 다시 깨어나고, 진행 상황은 그대로 남아요.

## 🗺️ 반딧불 마을 지도
```
┌──────────── 나무 ────────────┬──── 동쪽 숲 ────┐
│  🌳      🏠촌장 회관          │ 🌲  👾   🌲     │
│ 🏠코랄   🏮  광장  🏮  🏠토끼 │    👾      🌲   │
│ ═══════════ 큰길 ════════════ 문 ═════════════ │
│ 🏠거북이 🏮      🏮 🏪너구리  │ 🌲  ║   👾     │
│           🌊연못              │ 👾  ╚══  🐇아기 │
└──────────────────────────────┴────────────────┘
```
- 지금은 별이 사라진 **밤**이라 어두워요. 가로등과 창문 불빛, 반딧불이가 마을을 비춰요.
- 밤 색깔은 `main.tscn` → `NightTint`의 Color를 바꾸면 돼요. 흰색에 가까울수록 밝아져요.

### 바닥 타일 칠하기
- `scenes/village_tilemap.tscn`을 열고 `Ground`(바닥)나 `Deco`(울타리·덤불·긴 풀)를 선택해요.
- 화면 아래 **TileMap** 탭에서 타일을 고른 뒤 맵에 마우스로 칠하면 돼요.
- 물, 울타리, 덤불 타일은 코랄이 지나갈 수 없어요.
- `tools/build_village_tilemap.gd`는 처음 바닥을 자동으로 깔 때 쓴 스크립트예요. 다시 실행하면 직접 칠한 타일이 **덮어써지니** 조심하세요.

### 나무, 집, 가로등 옮기기
`main.tscn`의 `Objects` 아래에 있어요. 끌어서 옮기거나, `scenes/props/` 안의 장면을 끌어다 놓아서 더 추가할 수 있어요.

## 💬 NPC 대사 고치기 / 새 NPC 만들기
- **대사 고치기:** Godot에서 `scenes/main.tscn`을 열고 `OwlChief`를 선택해요. 오른쪽 인스펙터의 **Npc Name**(이름)과 **Lines**(대사 목록)를 고치면 돼요. Lines의 한 칸이 대화창 한 장이에요.
- **특별한 행동을 하는 NPC:** 스크립트 맨 위에 `extends NPC`라고 쓰고 `talk()` 함수만 새로 만들면 돼요. `raccoon_merchant.gd`를 참고하세요. 선택지는 `await Dialogue.ask(이름, 질문, ["예", "아니요"])`로 물어볼 수 있어요.
- **새 NPC 만들기:** `scenes/npc.tscn`을 `Objects` 아래로 끌어다 놓아요. 그다음 `Sprite2D`의 Texture에 그림을 넣고, 이름과 대사를 적으면 끝이에요.

## ⚔️ 전투 숫자 바꾸기
- **코랄:** `scenes/player.tscn`에서 `Player`를 선택하면 인스펙터의 **전투** 칸에 체력, 공격력, 무적 시간 등이 있어요.
- **슬라임:** `scenes/shadow_slime.tscn`에서 체력, 속도, 쫓아오는 거리를 바꿀 수 있어요.
- **슬라임 추가:** `shadow_slime.tscn`을 `Objects` 아래로 끌어다 놓으면 돼요.
